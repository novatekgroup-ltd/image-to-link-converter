# 🌙 NovaTek Image to Link Converter

**Zero‑API, fully dark mode, drag & drop image uploader** – get a permanent, shareable image link in seconds.

> 🚀 Live demo: [https://novatekgroup-ltd.github.io/image-to-link-converter/](https://novatekgroup-ltd.github.io/image-to-link-converter/)

## ✨ Features

- **No API key required** – uses free, anonymous service [0x0.st](https://0x0.st)
- **Dark mode by default** – easy on the eyes
- **Drag & drop or click** to select any image (PNG, JPG, WEBP, GIF)
- **Instant preview** before upload
- **One‑click copy** of the direct image URL
- **Fully client‑side** – your image never passes through our server
- **Responsive** – works on mobile, tablet, desktop

## 🛠️ How it works

1. You drop or select an image.
2. The file is uploaded directly to 0x0.st (secure HTTPS).
3. The service returns a permanent HTTPS link to your image.
4. Copy and share the link anywhere.

## 📦 Tech stack

- HTML5 / CSS3 (dark theme, flex, grid)
- Vanilla JavaScript (no frameworks)
- [0x0.st](https://0x0.st) – file hosting (max 512MB, retains files)

## 🧪 Run locally

Just open `index.html` in any modern browser – no build step, no server.
